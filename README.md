# 🕌 نظام إدارة العائلات والمتبرعين — جمعية الإحسان الخيرية

تطبيق عربيّ (يعمل من **اليمين إلى اليسار**) لمساعدة الجمعيات الخيرية على **تسجيل العائلات المنتفعة وأفرادها، والمتبرّعين، والمساعدات، والمداخيل والمصاريف** — مبنيّ انطلاقاً من كرّاس مواصفات «التطبيقة الإعلامية» الخاص بالجمعية.

> ✅ يعمل **دون اتصال بالإنترنت** ودون أي تثبيت — يكفي فتح ملف `index.html` في المتصفّح.
> 🔒 كل البيانات تُحفظ **محلياً على جهازك** (لا تُرسَل لأي خادم).

---

## ✨ المزايا

### 👨‍👩‍👧‍👦 المنتفعون (الحالات الاجتماعية)
ملف اجتماعي كامل لكل عائلة يطابق استمارة الجمعية:
- **المعطيات الشخصية:** الاسم، اللقب، الكنية، رقم ب.ت.و، تاريخ ومكان الولادة، الهاتف.
- **الضمان والتغطية الاجتماعية:** رقم الضمان، صلوحية البطاقة، نوع التغطية (ضمان / تعريفة منخفضة / علاج مجاني / بدون تغطية / متقاعد).
- **الوضعية العائلية:** الحالة العائلية، نوع العائلة، صنف الحالة (قارة/ظرفية/عاجلة)، و**جدول الأبناء** (الاسم، تاريخ الولادة، العمر التلقائي، المستوى الدراسي، العمل، الحالة الصحية).
- **الحالة الصحية:** مرض مزمن ونوعه، إعاقة ونوعها، الانتفاع بجراية.
- **الوضعية المادية:** العمل، تقدير الدخل، مداخيل أخرى.
- **السكن والعنوان:** نوع المسكن وثمن الكراء، العنوان والترقيم البريدي.
- رقم ملف **تلقائي** (مثال: `ع-2026-001`)، توصيف الحالة، العون المكلّف، وأرشفة بدل الحذف.

### 🤝 المتبرّعون
قائمة المحسنين مع **سجلّ تبرّعاتهم** (التاريخ، نوعية الإعانة، المناسبة، المقدار) ومجموع تبرّعات كل متبرّع.

### 💰 الشأن المالي
- **المساعدات الممنوحة** للعائلات.
- **التبرعات الواردة** من المحسنين.
- **المصاريف** و**المداخيل** العامة.
- لوحة مجاميع: إجمالي المداخيل، إجمالي المصاريف، و**الرصيد الصافي**.

### 📊 الرئيسية والإحصائيات
بطاقات إحصائية، توزيع العائلات حسب النوع والتغطية الاجتماعية، وآخر النشاطات.

### 🛠️ أدوات
- **بحث فوري** في كل القوائم.
- **طباعة** بطاقة الحالة الاجتماعية وسجلّ المتبرّع (مع خانتَي إمضاء العون ورئيس اللجنة).
- **تصدير Excel/CSV** للقوائم.
- **نسخ احتياطي واسترجاع** كامل بصيغة JSON (استبدال أو دمج).

## 🚀 طريقة التشغيل

1. حمّل المجلّد كاملاً.
2. افتح ملف **`index.html`** بنقرة مزدوجة (يُفضّل متصفّح Chrome أو Edge أو Firefox).
3. ابدأ بإضافة العائلات والمتبرّعين من الشريط الجانبي.

لا حاجة لإنترنت ولا لخادم ولا لأي تثبيت.

---

## 🖥️ تطبيق سطح المكتب (.exe لويندوز)

يمكن تشغيل التطبيق كبرنامج مستقلّ على ويندوز — **نافذة خاصّة به دون متصفّح، مع أيقونة على سطح المكتب**:

```bash
npm install        # تثبيت Electron (مرّة واحدة)
npm run icon       # توليد أيقونة التطبيق
npm run dist       # إنتاج ملف .exe محمول داخل مجلّد dist/
```

ينتج ملف **`dist/JamiatAlIhsan-1.0.0.exe`** — ملف تنفيذي واحد **محمول (Portable)** يكفي نسخه إلى سطح المكتب وتشغيله بنقرة مزدوجة، دون تثبيت ودون إنترنت. البيانات تُحفظ في ملفّ المستخدم وتبقى محفوظة بين كل تشغيل.

> لإنتاج **مُثبِّت (Setup)** ينشئ اختصارات سطح المكتب وقائمة ابدأ تلقائياً: `npm run dist:setup`.

## 💾 حول البيانات والنسخ الاحتياطي

- تُخزَّن البيانات في **التخزين المحلّي للمتصفّح** (`localStorage`) على نفس الجهاز والمتصفّح.
- ⚠️ **مهمّ:** خذ **نسخة احتياطية دورية** من قسم «الإعدادات ← تنزيل نسخة احتياطية»، واحفظها في مكان آمن (USB، بريد…).
- لنقل البيانات إلى جهاز آخر: نزّل النسخة الاحتياطية ثم استرجعها هناك.
- مسح بيانات المتصفّح قد يحذف السجلّات — لذلك النسخ الاحتياطي ضروري.

## 🗂️ بنية المشروع

```
jamiat-alihsan/
├── index.html            # الصفحة الرئيسية
├── css/styles.css        # التنسيق (RTL، ألوان الجمعية)
├── js/
│   ├── db.js             # طبقة تخزين البيانات + النسخ الاحتياطي
│   ├── utils.js          # أدوات (تنسيق، نوافذ، تنبيهات، طباعة، تصدير)
│   ├── beneficiaries.js  # المنتفعون / الحالات الاجتماعية
│   ├── donors.js         # المتبرّعون والتبرعات
│   ├── finance.js        # المساعدات والمصاريف والمداخيل
│   ├── dashboard.js      # الرئيسية والإحصائيات
│   ├── settings.js       # الإعدادات والنسخ الاحتياطي
│   ├── search.js         # البحث الشامل (عائلات + أفراد + متبرّعون)
│   └── app.js            # التنقّل والتحكّم العام
├── main.js               # عملية Electron (تطبيق سطح المكتب)
├── package.json          # إعداد البناء والأوامر
├── tools/make-icon.cjs   # توليد الأيقونة (ico/png)
└── build/icon.ico        # أيقونة التطبيق
```

## 🧰 التقنية

- **HTML5 + CSS3 + JavaScript** خالص (Vanilla) — بدون أي إطار عمل أو خطوات بناء للواجهة.
- خطوط **Cairo / Tajawal** عند توفّر الإنترنت، وإلا خطوط النظام.
- يعمل في المتصفّح على Windows / macOS / Linux وعلى الهاتف.
- نسخة سطح المكتب عبر **Electron + electron-builder** (ملف .exe محمول).
